# Physics-interactive-sim

Interactive browser-based simulations for understanding the physical world — built for anyone learning physics, structures, or engineering concepts.

Each module is a standalone HTML file. No installation. No login. Open in any browser.

---

## Simulations

---

## How to use

1. Click any link in the table above
2. Interact directly — drag arrowheads, adjust sliders, switch between methods
3. No download or account needed

To use offline, download the HTML file for any module and open it in your browser.

---

## What's inside each simulation

### Vector Bench
- Create vectors by setting magnitude and direction
- Add vectors using the **triangle law** (head to tail)
- Add vectors using the **parallelogram method** (shared tail)
- Resolve any vector into **x and y components**
- Drag arrowheads live on the canvas
- Resultant magnitude, direction, and component sums update in real time

---

## Built with

Plain HTML, CSS, and JavaScript (React via CDN). No build tools, no frameworks to install. Each file is self-contained and loads in any modern browser.

---

## For students

If a simulation is not loading, make sure you have an internet connection for the first load. After that, your browser caches it and it works offline.

For questions or feedback, contact your course instructor.
